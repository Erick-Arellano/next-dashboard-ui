# Carpeta de Migración de Datos (Vocali-Manager)

Coloca aquí tu archivo de Excel (`.xlsx`) o los archivos `.csv` con los datos reales de la escuela.

## Hojas sugeridas para la migración

1. **Alumnos** (Matrícula, Nombre, Grupo, Nivel, Teléfono, etc.)
2. **Profesores** (ID, Nombre, Email, Teléfono, etc.)
3. **Grupos / Clases** (Lista de grupos activos)
4. **Cursos / Asignaturas** (Idiomas enseñados)
5. **Cobros** (Historial o plantilla de cobros de alumnos)
6. **Pagos** (Historial o plantilla de pagos de profesores)

*Nota: Una vez que hayas colocado el archivo Excel en esta carpeta, házmelo saber para analizar sus columnas y estructurar el script de importación.*
